Sobre o projeto

O PyBank é um sistema bancário simulado, desenvolvido em Python, com funcionalidades de saque, depósito e investimentos em ações.

Esta interface foi criada em HTML/CSS/JS puro para demonstrar como o sistema funciona visualmente, ideal para portfólio no GitHub e LinkedIn.

Desenvolvido com foco em boas práticas de código, modularidade e experiência do usuário.
